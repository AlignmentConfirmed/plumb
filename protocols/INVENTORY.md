# INVENTORY — the protocol documents

The substrate is specified by six documents, each carrying its own
status header. An implementation can be written from these together with
`conformance/`.

| document | subject | conformance |
|---|---|---|
| `IS-1` WIRE | the record, the exact rational, the refusals | §9 vectors |
| `IS-2` SESSION | record boundaries, freshness, the arrival bound | — |
| `IS-3` REGISTRY | the tag grant table and the derivation rule | — |
| `IS-4` WITNESS | observer / witness / watcher, and the witness frame | — |
| `IS-5` HANDSHAKE | the declaration a peer sends | §7 vectors |
| `IS-6` CHAIN | the append-only act record | §7 act vectors |

Every byte-exact vector is generated by the codec and asserted against
the hex its document carries, so a document and its implementation
cannot drift silently. `conformance/MANIFEST.md` carries the corpus.
